# Portfolio Website

A responsive personal portfolio website to showcase your projects and skills. Built with HTML, CSS, and JavaScript, ready to be hosted on GitHub Pages.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Project Showcase**: Dedicated section to display your personal projects
- **Interactive Navigation**: Mobile-friendly hamburger menu
- **Contact Links**: Easy access to your email, GitHub, and LinkedIn profiles
- **Easy Customization**: Simple HTML structure for easy content updates

## Live Demo

Once deployed, your portfolio will be available at: `https://n1ghtylyc0de.github.io/Portfolio/`

## Getting Started

### Viewing Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/N1ghtlyC0de/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in your web browser:
   - Double-click the `index.html` file, or
   - Use a local web server (recommended):
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser

### Customizing Your Portfolio

1. **Update Personal Information**:
   - Edit `index.html` to add your name, bio, and skills
   - Update the hero section with your welcome message

2. **Add Your Projects**:
   - In the projects section, replace the placeholder project cards with your actual projects
   - Update project titles, descriptions, tags, and links
   - Add project images by replacing the placeholder divs

3. **Update Contact Information**:
   - Replace email, GitHub, and LinkedIn links with your actual profiles
   - Add or remove social media links as needed

4. **Customize Styling**:
   - Edit `styles.css` to change colors, fonts, and layouts
   - Modify CSS variables in `:root` for quick color scheme changes

## Hosting on GitHub Pages

### Method 1: Enable GitHub Pages (Recommended)

1. Go to your repository on GitHub
2. Click on **Settings**
3. Scroll down to **Pages** in the left sidebar
4. Under **Source**, select **Deploy from a branch**
5. Select the **main** branch and **/ (root)** folder
6. Click **Save**
7. Your site will be published at `https://n1ghtylyc0de.github.io/Portfolio/`

### Method 2: Using GitHub Actions (Advanced)

GitHub Actions can automatically deploy your site. The workflow is configured in `.github/workflows/` (if present).
